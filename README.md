# السعرات الحرارية + المنظّم الذكي

تطبيق ويب عربي (RTL) لتتبع السعرات والتغذية والتمارين، ومعه **المنظّم الذكي**: مساعد بالذكاء الاصطناعي ترتّب معه مهامك وتذكيراتك ومواعيدك وملاحظاتك.

التطبيق يعمل **لمستخدم واحد بدون تسجيل دخول**. إذا رفعته على الإنترنت، ضع كلمة مرور في `APP_PASSWORD` حتى لا يدخل أحد غيرك.

## المتطلبات
- Node.js 20.12 أو أحدث
- قاعدة بيانات PostgreSQL
- مفتاح OpenAI API (للمزايا الذكية فقط، وبقية التطبيق يعمل بدونه)

## التشغيل على جهازك
```bash
npm install
cp .env.example .env      # ثم عبّئ القيم داخل .env
npm run db:push           # ينشئ الجداول في قاعدة البيانات (مرة واحدة، وبعد أي تغيير في الجداول)
npm run dev               # يفتح على http://localhost:5000
```

## الرفع على الإنترنت والحصول على رابط (Render، مجاناً)
1. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
2. اختر **New → Blueprint** واختر هذا المستودع. يقرأ Render ملف `render.yaml` وينشئ التطبيق وقاعدة البيانات.
3. عبّئ المتغيرات التي يطلبها: `OPENAI_API_KEY` و`APP_PASSWORD` و`OWNER_NAME`.
4. بعد انتهاء البناء يعطيك رابطاً مثل `https://calorie-organizer.onrender.com`.

الجداول تُنشأ تلقائياً عند كل تشغيل. في الخطة المجانية ينام التطبيق بعد فترة بلا استخدام، وقاعدة البيانات المجانية تنتهي بعد مدة يحددها Render.

**بدائل:** أي استضافة تدعم Docker (Railway، Fly.io، سيرفر خاص) تستطيع تشغيل `Dockerfile` الموجود. يكفي أن تعطيها `DATABASE_URL`.

## تثبيته على الجوال والتنبيهات
- افتح الرابط من الجوال، ثم اختر "إضافة إلى الشاشة الرئيسية" ليصير مثل التطبيق. على الآيفون هذه الخطوة ضرورية للتنبيهات.
- في صفحة المنظّم اضغط **تفعيل** في بطاقة التنبيهات، فتصلك التذكيرات حتى لو كان التطبيق مغلقاً.
- مفاتيح التنبيهات تُنشأ تلقائياً وتُحفظ في قاعدة البيانات. لا تحتاج إعداد أي شيء.

## متغيرات البيئة
| المتغير | مطلوب | الوصف |
|---|---|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL |
| `OPENAI_API_KEY` | للمزايا الذكية | مفتاح OpenAI |
| `OPENAI_BASE_URL` | لا | خادم متوافق مع OpenAI بدل الافتراضي |
| `APP_PASSWORD` | يُنصح به | كلمة مرور للموقع كاملاً (يطلبها المتصفح) |
| `OWNER_NAME` | لا | الاسم الذي يظهر في أعلى التطبيق |
| `PORT` | لا | المنفذ (الافتراضي 5000) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | لا | مفاتيح التنبيهات، وإذا تُركت تُنشأ تلقائياً |

## البنية
- **الواجهة:** React 18 + TypeScript + Vite + Tailwind + shadcn/ui، والتوجيه بـ Wouter، والبيانات بـ TanStack Query (`client/`)
- **الخادم:** Express + TypeScript (`server/`)
- **قاعدة البيانات:** PostgreSQL + Drizzle ORM، والجداول في `shared/schema.ts`
- **الذكاء الاصطناعي:** OpenAI (`gpt-4o-mini` و`gpt-4o`)

### المزايا
- تسجيل الوجبات والماء والوزن والقياسات، وتحليل صورة الوجبة، وقراءة الباركود
- مطاعم سعودية بقوائمها، ووصفات، وتمارين مع مؤقت، وتحديات يومية، وإحصائيات
- **المنظّم الذكي** (`/organizer`): محادثة بالعربي (كتابة أو صوت) تتحول إلى مهام وتذكيرات ومواعيد وملاحظات، مع مهام وتذكيرات متكررة (يومي، أسبوعي، شهري) وتنبيهات تصل حتى والتطبيق مغلق. الكود في `server/organizer.ts` و`client/src/pages/Organizer.tsx`.
