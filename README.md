# السعرات الحرارية + المنظّم الذكي

تطبيق ويب عربي (RTL) لتتبع السعرات والتغذية والتمارين، ومعه **المنظّم الذكي**: مساعد بالذكاء الاصطناعي ترتّب معه مهامك وتذكيراتك ومواعيدك وملاحظاتك.

التطبيق يعمل **لمستخدم واحد بدون تسجيل دخول**. إذا رفعته على الإنترنت، ضع كلمة مرور في `APP_PASSWORD` حتى لا يدخل أحد غيرك.

## المتطلبات
- Node.js 20.12 أو أحدث
- قاعدة بيانات PostgreSQL
- مفتاح OpenAI API (للمزايا الذكية فقط، وبقية التطبيق يعمل بدونه)

## التشغيل على جهازك
```bash
npm install
cp .env.example .env      # ثم عبّئ القيم داخل .env
npm run db:push           # ينشئ الجداول في قاعدة البيانات (مرة واحدة، وبعد أي تغيير في الجداول)
npm run dev               # يفتح على http://localhost:5000
```

## الرفع على أي استضافة (Render، Railway، Fly.io، سيرفر خاص...)
1. أنشئ قاعدة PostgreSQL (أغلب الاستضافات توفرها).
2. ضع متغيرات البيئة من `.env.example` في لوحة الاستضافة، وأهمها `DATABASE_URL` و`OPENAI_API_KEY` و`APP_PASSWORD`.
3. أمر البناء: `npm install && npm run build`
4. أمر التشغيل: `npm start`
5. شغّل `npm run db:push` مرة واحدة مع نفس `DATABASE_URL`، من جهازك أو من طرفية الاستضافة.

التطبيق يستمع على المنفذ `PORT` الذي تحدده الاستضافة.

## متغيرات البيئة
| المتغير | مطلوب | الوصف |
|---|---|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL |
| `OPENAI_API_KEY` | للمزايا الذكية | مفتاح OpenAI |
| `OPENAI_BASE_URL` | لا | خادم متوافق مع OpenAI بدل الافتراضي |
| `APP_PASSWORD` | يُنصح به | كلمة مرور للموقع كاملاً (يطلبها المتصفح) |
| `OWNER_NAME` | لا | الاسم الذي يظهر في أعلى التطبيق |
| `PORT` | لا | المنفذ (الافتراضي 5000) |

## البنية
- **الواجهة:** React 18 + TypeScript + Vite + Tailwind + shadcn/ui، والتوجيه بـ Wouter، والبيانات بـ TanStack Query (`client/`)
- **الخادم:** Express + TypeScript (`server/`)
- **قاعدة البيانات:** PostgreSQL + Drizzle ORM، والجداول في `shared/schema.ts`
- **الذكاء الاصطناعي:** OpenAI (`gpt-4o-mini` و`gpt-4o`)

### المزايا
- تسجيل الوجبات والماء والوزن والقياسات، وتحليل صورة الوجبة، وقراءة الباركود
- مطاعم سعودية بقوائمها، ووصفات، وتمارين مع مؤقت، وتحديات يومية، وإحصائيات
- **المنظّم الذكي** (`/organizer`): محادثة بالعربي (كتابة أو صوت) تتحول إلى مهام وتذكيرات ومواعيد وملاحظات، مع تنبيهات عند حلول الموعد ما دام التطبيق مفتوحاً. الكود في `server/organizer.ts` و`client/src/pages/Organizer.tsx`.

> ميزة الأصدقاء وتحدياتهم مصممة لعدة مستخدمين، فلن تفيد كثيراً في وضع المستخدم الواحد.
